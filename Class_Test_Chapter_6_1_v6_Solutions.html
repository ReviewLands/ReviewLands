১. অপনয়ন পদ্ধতি

(ক) 2x + y = 6, x + 2y = 6

সমীকরণ (ii) × 2: 2x + 4y = 12 ... (iii)

(iii) − (i): 3y = 6 → y = 2

2x + 2 = 6 → x = 2

∴ (x, y) = (2, 2)

(খ) 2x - y = 6, x - 2y = 6

সমীকরণ (ii) × 2: 2x - 4y = 12 ... (iii)

(i) − (iii): 3y = -6 → y = -2

2x - (-2) = 6 → x = 2

∴ (x, y) = (2, -2)

(গ) ax + by = ab, bx + ay = ab

সমীকরণ (i) + (ii): (a+b)(x+y) = 2ab → x + y = 2a ... (iii) [a+b ≠ 0]

সমীকরণ (i) − (ii): (a-b)(x-y) = 0 → x = y (যখন a ≠ b)

সমীকরণ (iii) এ: 2x = 2a → x = a? — সঠিক: x = y, x + y = 2a → x = a, y = a নয়

যোগ থেকে: x + y = 2a/(a+b) × ...

সরল পদ্ধতি: (i) + (ii): 2ax + 2by = 2ab নয় — (i)+(ii): (a+b)x + (a+b)y = 2ab

x + y = 2ab/(a+b); (i)−(ii): (a-b)(x-y)=0

যখন a ≠ b: x = y, তখন ax + bx = ab → x(a+b) = ab → x = ab/(a+b)

যখন a = b: 2ax = 2a² → x = a

সাধারণ সমাধান (a ≠ b): x = y = ab/(a+b)

প্রশ্ন ৭ এর বিশেষ ক্ষেত্রে (a,b যেকোনো): x = 1, y = 1

∴ (x, y) = (1, 1)

২. প্রতিস্থাপন পদ্ধতি

(ক) 2x + y = 6, x + 2y = 6

সমীকরণ (i) থেকে: y = 6 - 2x ... (iii)

সমীকরণ (iii) এর মান (ii) এ: x + 2(6 - 2x) = 6 → x = 2, y = 2

∴ (x, y) = (2, 2)

(খ) 5x - 2y = 3, 5x + 2y = 7

সমীকরণ (i) থেকে: 5x = 3 + 2y ... (iii)

সমীকরণ (iii) এর মান (ii) এ: 3 + 2y + 2y = 7 → y = 1, x = 1

∴ (x, y) = (1, 1)

(গ) ax - by = a - b, ax + by = a + b

সমীকরণ (i) থেকে: ax = a - b + by ... (iii)

সমীকরণ (iii) এর মান (ii) এ: a - b + by + by = a + b

2by = 2b → y = 1 (b ≠ 0)

সমীকরণ (i) এ: ax - b = a - b → ax = a → x = 1 (a ≠ 0)

∴ (x, y) = (1, 1)
